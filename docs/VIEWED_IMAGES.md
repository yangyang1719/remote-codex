# Codex 已查看图像记录

2026-10-27。远端实际协议通过 `imageView {id,path}` 记录图像查看；先前主聊天的 native 历史过滤、前端类型过滤/渲染和子代理内容归一化均未接入，导致桌面不显示。此项与用户上传图片附件是不同的记录。

现在主聊天和子代理消息内均显示“已查看 1 张图像”，正在进行的实时事件显示“正在查看 1 张图像”。记录可收起，展开显示缩略图，点击缩略图使用现有系统预览。历史、只读自动跟进和实时 item 更新均支持；不会为了显示图片重新运行模型工具或取得会话写入权。

## 图片读取边界

- Native `ViewedImageStore` 只登记来自远端真实 `imageView` 的图片路径，按连接作用域、源 thread 和 item ID 隔离。前端仅提交这些标识，不能自选文件路径。
- 预览需属于当前主会话，或当前展开的子代理；切换连接/会话后丢弃过期响应。
- 已记录图片可能在 `/tmp` 等项目外目录。仅专门的查看记录读取路径允许这一情况；普通附件/文件预览的目录限制保留。
- SSH 仅读取普通文件，限制 25 MiB，并校验图像文件头；本地 ImageIO 限 4000 万像素并下采样生成最大 240 px 缩略图。不会执行图像内容或从图片路径发起 URL 请求。
- 前端在记录进入视野后按需读取，最多两项并发，保留折叠和滚动状态。图片已被远端清理时，仍显示历史查看记录，并提供不可用提示和手动重试。
