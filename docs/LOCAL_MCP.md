# 本地 MCP

客户端左下「本地 MCP」用于管理在这台 Mac 上运行的 stdio MCP 服务，让远端 Codex 经 SSH 调用。初始没有服务，远端访问关闭；保存配置不会启动程序，也不会建立远端连接。

## 使用

1. 打开「本地 MCP」→「添加 / 编辑配置」，粘贴 MCP 提供方给出的 stdio 配置。
2. 保存后点击对应服务的「启动」，完成 MCP 握手；「查看工具」显示服务实际返回的工具和参数定义。
3. 在客户端打开已有 Codex 会话，点击「允许当前会话」。客户端建立独立 SSH 反向通道，将此 Mac 专用的适配器登记到当前远端 App Server 配置，并请求刷新 MCP。
4. 在该会话中要求 Codex 调用本地功能。远端先用 `local_mcp_list_tools` 获取服务与工具，再通过 `local_mcp_call` 调用准确的工具及参数。
5. 用「撤销当前会话」收回该会话权限；用「关闭远端访问」关闭整条本地 MCP 通道。服务的「停止」仅结束该服务的本地进程。

示例仅说明配置格式，需要替换成已安装、可信的 MCP 命令与实际路径：

```json
{
  "mcpServers": {
    "example": {
      "command": "/absolute/path/to/mcp-server",
      "args": [],
      "env": {},
      "cwd": "/absolute/path/to/workspace"
    }
  }
}
```

`args` 是参数数组，不经 Shell 解释或展开。可省略 `env`、`cwd`。支持标准命令名查找，但从 Finder 启动时 PATH 可能与终端不同，优先使用绝对路径。配置内的 `enabled` 字段不触发自动启动，仍由用户点「启动」。修改整体配置会关闭原本地 MCP 子进程；存在工具调用时拒绝修改，等待完成后再改。

仅添加可信来源的配置，命令会以当前 Mac 用户身份运行。当前最多 16 个服务、每服务 500 个工具；工具目录上限 1 MiB，调用请求和结果上限 2 MiB，超限返回错误。

允许一个会话后，该会话可以访问所有已启动的本地 MCP 服务；不同会话需要分别允许。之后切换联系人、项目或窗口不会把旧授权改投其他会话。切换 SSH 主机关闭本窗口管理的本地 MCP，防止旧主机继续访问。

## 通道与配置

```text
远端 Codex → stdio MCP 适配器 → 远端私有 Unix socket
                                      ↓ SSH 反向转发
                             Mac 回环接口 → 本地 stdio MCP
```

Mac 不需要开放公网端口或启用 SSH 服务。远端需要允许 SSH Unix socket 反向转发，并提供 Python 3。Mac 通过 `/usr/bin/python3` 运行管理器，需要已安装相应开发工具。初次允许时，仅在远端用户私有目录放置适配器和连接配置。

每台 Mac 有独立设备 ID 和 MCP 配置项；只写自己的 `mcp_servers.mac_local_*`，同名内容不匹配则停止，不覆盖其他 MCP。使用官方 `config/value/write` 和 `config/mcpServer/reload`，不重启 Codex、不恢复或中断原会话。已加载会话可能到安全边界才看到新工具。接口见 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。

已知当前会话由另一个已连接官方实例持有时，配置请求路由到该实例。未与客户端共享服务的独立 CLI 可能需要自行刷新 MCP 配置；客户端不会代它重启。

## 生命周期与数据

- 服务配置、参数和环境变量保存在 Mac 的私有应用数据目录 `RemoteCodex/LocalMCP/`，目录 0700、配置文件 0600；不写项目仓库或上传给远端。
- 远端仅保存适配器、私有 socket 路径和随机连接凭据，不保存本地 MCP 的启动参数、环境变量或账号密钥。工具调用结果会通过 SSH 返回远端 Codex，内容取决于用户选择的 MCP。
- 通道校验随机凭据、拒绝浏览器 Origin，并按 Codex 传输元数据核对已允许的会话；不按工具参数猜测身份，不继承父会话授权给子代理。
- 安全边界包括 Mac 本机账户与远端 SSH 账户。同一远端账户内能读取私有连接凭据的程序仍处于信任范围，不能把会话核对视为针对该账户的强租户隔离。
- SSH 断线按退避重建通道，更新连接凭据；不重放工具调用。超时、断线或停止时，操作结果可能未知，先检查实际效果，不能自动重试。
- 关闭远端访问立即撤销新调用权限；已经开始的操作可能已经生效，不自动回滚。退出客户端关闭本窗口的通道和受管子进程，远端 Codex 自身继续运行。
- 重新启动客户端不自动启动本地服务或恢复授权。远端已登记的适配器可保留；Mac 离线时调用返回不可用，需要重新在客户端启用。
- 同一台 Mac 当前仅由一个客户端窗口管理这些服务；其他窗口会提示已有管理者，需在原窗口操作或退出该窗口后接手。

## 当前范围

支持 stdio 的初始化、工具目录及分页、工具调用、取消超时、服务进程启停与 SSH 断线恢复。不预装或下载第三方 MCP，不提供内置的任意 Shell、文件、剪贴板或浏览器工具。

暂未支持 HTTP/SSE MCP、OAuth 登录、resources/prompts、roots、sampling 和 elicitation；这些服务端请求不会被自动批准。具体第三方 MCP 的兼容性需要选定服务后单独验收。
