# 用量命令

更新：2026-10-26。

在输入框输入 `/usage` 后回车，或点 `/` 菜单中的“用量”。也支持 `/status` 别名。命令由客户端处理，不作为聊天内容发送；只读占用状态也能查看，无需继续此会话或取得 writer。

窗口提供：

- 远端账号额度：按接口真实返回的额度分组与窗口周期显示已用、剩余及重置时间。不假定 primary 必为五小时；远端只返回七天窗口时就只显示七天。
- 账号 Token 活动：累计、单日最高、最近统计日期及该日数值。缺失/空值显示“暂无数据”，不会当成 0；真实 0 保持为 0。
- 当前会话 Token：优先显示官方会话记录的最近 token_count 快照及时间，含累计、输入、缓存输入和输出。没有快照时显示可用的远端预估分组；实时 tokenUsage 通知到达时更新。缓存输入是输入的子集，不能再次相加。
- 记录快照仅表示对应主会话的数据；不额外合计子代理、未落盘请求或其他客户端的独立会话。账号 Token 数与额度百分比含义不同，不按 token 数反推剩余额度。

可以手动刷新；窗口打开时每 60 秒刷新。额度变更通知也会触发读取。关闭后停止定时刷新；切换项目/会话时关闭窗口并丢弃旧响应。断线保留旧数值并明确标注，重连后可刷新。重置时间按 Mac 本地时区显示。

数据全部来自现有远端登录：`account/rateLimits/read`、`account/usage/read`，会话预估加 threadId。远端会话预估返回 null 时，只读读取 `thread/read` 元数据中的 rollout 路径，并用 SSH 提取最近 token_count。此操作不加载或 resume 会话。

只读快照脚本校验 UUID、官方 sessions/archived_sessions 路径、常规文件和 session_meta 身份；不跟随文件自身的符号链接。最多读取文件尾部 8 MiB，仅输出合法数值和时间，不返回消息正文、工具日志或认证内容。找不到快照时保持“暂无数据”，不扫描整段历史冒充最新数据。

本功能不会登录、退出、重置额度、消费重置次数、购买额度、发送邮件、修改目标或启动模型回合。Mac 不需要登录 Codex，账号显示指远端账号。
