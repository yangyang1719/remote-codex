# 运行状态、思考摘要与失败提示

2026-10-28：按官方 0.165.0 schema 与 App Server 文档接入。

## 失败提示

`error` 通知保留 `message`、`codexErrorInfo`、`additionalDetails`、`turnId` 和 `willRetry`。`turn/completed` 的失败详情也会显示；两者按会话/回合合并，不重复叠卡。直接发送 RPC 失败仍可按原文识别 capacity。

满载提示使用独立区域，不与只读/连接横幅互相覆盖；详情默认收起，能看到远端原文、请求标识和错误类型。提示保留到关闭、新回合开始或远端自动重试后确有新进展；切换会话回来仍保留。只显示本主机/会话的提示。

「切换模型」打开远端目录选择器，保存使用已有 thread/settings/update 路径，模型不可操作时禁用。保存不自动重发消息、不清理草稿；等待用户手动发送。原错误标记为上次请求，避免将它当成新模型的错误。

新打开历史时从最新 turn/error 恢复；读取更早分页不覆盖当前状态。原生版本号保护读取期间发生的新事件，浏览器保留实时状态，避免旧快照回退。未提供对应数据时不猜失败原因。

## 思考与摘要

主聊天底部根据实际事件显示思考中、运行中、执行命令、使用工具、正在回复、等待处理、自动重试。只读观察同样能显示进度，不因此取得写入权。断线时停止动画并提示待同步；完成、失败和中断后停止运行状态。

接收 `reasoning.summary` 和 `item/reasoning/summaryTextDelta` / summaryPartAdded。摘要默认收起，浅灰单行预览，点开查看完整可见摘要；流式更新保留手动展开。底部不重复显示聊天中已有的摘要。未提供摘要时只显示状态，不编造摘要文本。

空数组、缺少摘要或只有空白的 reasoning 条目不生成聊天行，也不占历史分页数量。流式正文到达后才显示摘要；更新为空时移除原摘要节点，避免缓存留下空标题。没有摘要内容时仍可显示底部运行状态。

**不转发** `reasoning.content`、encryptedContent 或 `item/reasoning/textDelta`。turn 通知/快照不携带原始 items，历史条目只白名单传递 summary。子代理内联面板沿用其既有过滤，不新增原始推理读取。
