# 远端账号与设备授权

入口为客户端左下「远端账号」。显示当前远端 ChatGPT 邮箱/套餐或 API Key 认证方式。已登录时按钮为「退出并登录其他账号」：先退出并确认远端已登出，再申请设备授权码。在官方网页登录目标账号并输入代码；短信、邮箱或其他身份验证由官方网页处理。

## 作用范围

这是当前连接的远端官方 app-server 所用登录环境，不是每个聊天的独立账号。共用该环境的 CLI/客户端会受账号变更影响。独立进程可能保留内存中的旧认证，不能承诺所有已有终端即时切到新账号；必要时重新打开该终端中的 CLI。原聊天记录和项目不删除。

实现直接使用远端官方 0.165.0 的 `account/logout` → `account/read(refreshToken:false)` 确认 account 为 null → `account/login/start(type: chatgptDeviceCode)`，以及 cancel、login/completed、account/updated。不自己改写 auth.json，没有账号凭据备份或多账号密钥库。成功后重新读取账号、用量和模型目录；未登录状态也能使用账号入口。

## 凭据与生命周期

- OAuth token 由远端官方进程保存和刷新。Mac 仅拿到邮箱/套餐、授权 URL 和一次性设备码；不接收 access/refresh token，不记录设备码到草稿、localStorage、日志或证据文件。
- 浏览器只打开官方 `https://auth.openai.com/codex/device`，URL 由已绑定的本次远端响应提供，不能由任意页面数据传入。可复制设备码到剪贴板。
- 取消只使用本客户端持有的准确 loginId。关闭授权面板、正常退出客户端及切换项目时尝试取消本次未完成授权，不再次 logout。网络中断时显示结果未确认；重新连接后读取当前账号，不根据旧邮箱或旧授权码推断成功。
- 2026-10-28 用户明确改为先退出后登录。只有发起按钮执行 logout；打开/刷新/关闭面板不会退出账号。退出失败或读回仍有身份时停止，不继续发起登录。确认退出后若新授权失败、过期或取消，旧账号不会自动恢复，需要重新登录。此顺序是用户选择，并非宣称官方推荐；实际登录结果以官方通知与 account/read 为准。

## 任务保护与边界

发起前读取已连接官方实例的诊断。存在活动回合时拒绝；新进程未产生计数时读取已加载会话状态确认，缺失/未知结果拒绝。授权等待中每两秒复查，发现任务启动或状态不可确认时尝试取消本次授权；本客户端此时不启动新模型工作。

检查和账号完成授权不是服务端原子事务；独立终端、未连接的另一个 daemon 以及恰在授权完成时开始的任务不能保证被完整拦住。所以操作界面明确要求共用该登录环境的任务先空闲。本功能不抢会话、不调用 interrupt、不停止或重启服务，也不通过关闭其他客户端实现空闲。
